# Feedback Collector - Backend

## Description

The Feedback Collector backend, responsible for managing the system's logic and internal operations.

This part of the project handles processing requests from the frontend, managing information, and handling communication with the database via an API.

## Technologies

- TypeScript

## Key Features

- User and role management.
- Feedback logging and administration.
- Management of Areas, Managers, ICs, and projects.
- Querying and filtering records.
- Administration of information stored in the database.
- Communication with the frontend via the API.

## Installation and Execution

1. Clone the repository.
2. Navigate to the `back` folder.
3. Install the dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm run dev
```
