# Feedback Collector

* Feedback Collector is an internal tool designed to centralize the recording and tracking of performance feedback within an organization.

* The goal is to replace the use of separate documents and spreadsheets with a single system, facilitating information management and allowing for the visualization of team performance.

# Features

* Feedback logging with comments, screenshots, and ratings.
* Chronological history by person.
* Search and filter records.
* Export information in CSV format.
* General and department-specific dashboards.
* Management of the organizational structure and projects.
* Different access levels based on the user’s role.

# Repository Structure

The project is organized into two main modules:

* back: contains the backend, the API, and the database.
* front: contains the user interface.

Each module has its own README file, which contains the corresponding documentation.

# Users

* Manager: records and tracks feedback from their ICs.
* Director: accesses general information about the Areas and can record feedback on Managers.

# Project Objective

* Centralize information, improve feedback traceability, and facilitate performance tracking within the organization.
